# Domino Sky submission copy

## Description

Domino Sky helps an airline controller see how one airport closure spreads through aircraft, passenger connections and crew duty, then compare a feasible recovery before applying it. Its deterministic engine calculates every figure. Gemini reviews verified candidates; optional Supabase saves preserve scenario inputs with session isolation.

## Demo sequence

0-15 seconds: Open cockpit, run Mumbai 14:30-16:00 closure. Show the network and delayed flight metrics.

15-35 seconds: Select DS0303 on the timeline and trace its inbound aircraft cause. Show passenger connection and crew consequences.

35-65 seconds: Preview the recommended recovery. Show the spare/cancel action list and before/after comparison, including the explicit cancellation cost. Apply, inspect a canceled flight, then undo.

65-90 seconds: Ask Gemini to review verified plans when configured; save and reload a scenario. Explain that all numbers remain engine facts and optional service failures preserve the simulator.
